HOW TO OPEN IN VISUAL STUDIO CODE
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in your browser, or use the Live Server extension.

IMPORTANT: ACTIVATE THE CONTACT FORM
The contact form uses FormSubmit (https://formsubmit.co), a third-party form-to-email service.
1. In script.js, confirm CONTACT_EMAIL is your correct email address.
2. Publish/deploy the website or test it using a hosted URL.
3. Submit the contact form once using a real email address.
4. Check your inbox for FormSubmit's activation email and confirm the activation.
5. Submit another test message to verify delivery.

The Gmail and Outlook buttons open a prefilled draft; the visitor still presses Send.
The contact form submits to FormSubmit and can deliver the message to your inbox after activation.
Do not put passwords, email login credentials, or private API keys in these files.
